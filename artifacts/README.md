# Artifact archive

`raw/` contains unmodified files copied from HiPerGator in September 2026. Do not edit these files in place. `sanitized/` contains the one notebook that required credential removal; its original and sanitized hashes are recorded in [`SANITIZATION.md`](SANITIZATION.md).

`metadata/` contains reconstruction metadata extracted from the historical files. `derived/` contains public sufficient statistics and aggregates created during the private audit. `MANIFEST.csv` and `checksums.sha256` cover the raw archive and are generated by `scripts/build_manifest.py`.

`RESTRICTED_ARTIFACTS.csv` records paths, sizes, SHA-256 hashes, filesystem ownership, and preservation status for the 30 collaborator-owned files whose bytes are kept out of the public repository.

The archive includes all notebooks found in the identified thesis, DiffLogic, ExpLogic, EcoLogic, visualizer, FPGA-backup, and early SKEPTIC state-embedding trees. A broader search also found notebooks belonging to unrelated diffusion, transformer, and rolling-shutter projects; those are outside this thesis archive's scope.

One historical file, `orange_visualizer/notebooks/model-training/LogoIdeation.ipynb`, has an `.ipynb` name but is not valid notebook JSON. Its bytes and checksum match HiPerGator, so it is retained and marked `invalid-notebook` in the notebook index rather than repaired speculatively.

On September 16, 2026, every raw manifest entry was hashed both locally and at its recorded HiPerGator source path. Every SHA-256 digest matched.
